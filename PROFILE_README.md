## 🔥 Featured Project

### 🧀 FetaCheese Bot
A sophisticated Chess Bot written in C# for [Sebastian Lague's Chess Coding Challenge](https://github.com/SebLague/Chess-Challenge). The challenge? Implement a competitive chess engine within strict token limits.

**Key Features:**
- **Alpha-Beta Negamax Search**: Efficient minimax algorithm with alpha-beta pruning
- **Iterative Deepening**: Dynamic depth adjustment based on available thinking time
- **Quiescence Search**: Evaluates tactical sequences to avoid the horizon effect
- **Move Ordering**: Prioritizes promising moves for better pruning efficiency
- **Delta Pruning**: Optimizes quiescence search performance
- **Endgame Evaluation**: Specialized logic for king mop-up and mobility assessment
- **Time Management**: Adaptive thinking time allocation
